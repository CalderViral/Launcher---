# Launcher---
Launcher — удобный лаунчер для RAGE MP на Python (CustomTkinter). Проверяет Steam/RAGE MP, показывает онлайн, отображает новости, копирует IP, сохраняет настройки в JSON. Доступен как готовый .exe и как открытый код — легко адаптировать под любой сервер. Перед использованием ознакомьтесь с README.md и README1.txt
